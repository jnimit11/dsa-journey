# Stack

This folder is dedicated to stack data structure programs and exercises.

## What is a stack?

A stack is a linear data structure that follows the Last In, First Out (LIFO) principle.

- The most recently added item is processed first.
- Common operations include:
  - push: add an item
  - pop: remove the top item
  - peek: view the top item without removing it
  - isEmpty: check whether the stack is empty

## Typical stack use cases

- Function call management
- Expression evaluation
- Undo/redo features
- Backtracking algorithms

## Example behavior

If you push values 10, 20, and 30 in order, the stack will pop in this sequence:

30
20
10
